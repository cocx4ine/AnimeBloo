## Overview

AnimeBloo is a minimal desktop app for discovering, organizing, and watching anime on Windows and Linux. Browse the catalog, choose a series, and move through its episodes in one place. For each episode, you can select the available Sub or Dub version, audio track, and subtitles. Your viewing history helps you pick up where you left off, with progress kept in sync for a smooth watching experience.

## Features

1. **Clean, responsive interface** for browsing the catalog and finding what to watch.
2. **Compact controls below the banner** for quick access to the actions you need.
3. **Episode-level Sub and Dub selection** so you can choose how to watch each episode.
4. **Audio and subtitle choices** based on the tracks available for the selected episode.
5. **Viewing history** that keeps track of watched episodes and helps you resume.
6. **Multilingual interface** for navigating the app in your preferred language.

## Installation

### From Releases (Recommended)

1. Open the [Releases](../../releases) page.
2. Download the latest installer or prebuilt package for Windows or Linux.
3. Run the installer or open the package to start AnimeBloo.

### From Source

Install Git, Node.js, and npm, then run:

```bash
git clone https://github.com/<owner>/AnimeBloo.git
cd AnimeBloo
npm install
npm start
```

Replace `<owner>` with the repository owner's GitHub username or organization name.

To generate a package, run:

```bash
npm run build
```
